# Hypothesis R2 (open)

Shape: N = r^3 s, distinct primes r, s ≥ 5.

Already theorems in the paper:
- if m is an integer then r^2 divides L(p) = p^3 - p^2 - 12
- p > r is empty
- therefore any remaining solution satisfies p < r < p^{3/2} and r^2 | L(p)

Search recorded 12 September 2026:
- no prime p ≤ 2000 has a prime-square factor r^2 | L(p) with r > p
- restricted to p ≡ 1 or 13 (mod 16), no u = 1 point L(p) = r^2 for p < 20000
- same residue classes, no r > p with r^2 | L(p) for p < 3000

This is evidence, not a proof that R2 is empty.
