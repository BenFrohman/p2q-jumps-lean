# Historical verification documents (not certificates)

The files in this folder are kept only as a historical record. They are
not the certificate of record.

`verification_certificate-821e35e.tex` and
`verification_certificate-821e35e.pdf` were previously at
`paper/verification_certificate.*`. They describe an older commit
`821e35e305306d0dd33a35926d52d21fa5b99a58` and four declarations
(`g_ge_six`, `g_sub_six_eq`, `quad_sos`, `theorem28_from_paper`), citing
GitHub Actions run 41568060001. That table is incomplete relative to the
current development, and the document itself is not an official CI
artifact.

The certificate of record is the official `certify.yml` artifact named in
the repository root `CERTIFICATE.md`.

`updated_residual_section.tex` was previously at `paper/updated_residual_section.tex`. It is a superseded draft section and is not the deposited text; the deposited v1.4.1 paper is `paper/p2q-jumps-v1.4.tex` on branch `paper/v1.4.1-20261123`.
