# Certificate audit, 17 Nov 2026 (America/Chicago)

Rules audited (Benjamin Stanley Frohman, 17 Nov 2026, 1:33–1:56 AM CT):

1. Every lake build and certificate attempt (pass, fail or partial) runs from this repo's own committed
   `lake-manifest.json` and ships with that manifest, its sha256, the commit, `lean-toolchain`, the
   Mathlib rev, elan/lake versions, the full build log and the `#print axioms` output.
   Hand-written summaries never count as certificates.
2. No dummy certificates: the final pass rests only on the real Lean kernel. External tools (PARI,
   Python/SymPy, `scripts/p7/gen_kernel.py`) may only generate data that the kernel then checks; they
   never prove or pass anything on their own.

## Mechanism from now on (revised 17 Nov 2026, 2:53 AM CT rule)

**The certificate of record is only the GitHub Actions artifact `lean-certificate-<commit sha>`** from a
fresh `.github/workflows/certify.yml` run on the pushed commit, built from the repo's committed
`lake-manifest.json`. The workflow runs `CERT_OUT=cert-out scripts/cert-bundle.sh`, which refuses to
build if the manifest differs from the committed one and records, verbatim and unexcerpted:
`lake-manifest.json`, `lake-manifest.json.sha256`, `lean-toolchain`, `lakefile.toml`, `env.txt` (commit,
Mathlib rev, elan/lake/lean versions, GitHub run id, exit codes), `cache-get.log`, the full
`lake-build.log`, the full `scan-sorry-axiom.log`, the full `print-axioms.log`, `STATUS` and `SHA256SUMS`.
A pass (build, scan and `#print axioms` exit 0, only propext / Classical.choice / Quot.sound) adds a
`CERTIFICATE` file and is uploaded as `lean-certificate-<sha>`. Any other outcome adds
`FAILED-NOT-A-CERTIFICATE.txt` and is uploaded as `lean-attempt-FAILED-NOT-A-CERTIFICATE-<sha>`.

Runs of the same script on a local machine write to `local-dev-logs/<time>-CT-<commit>/` with
`NOT-THE-OFFICIAL-CERTIFICATE.txt`. They are development logs, never certificates. The two bundles that
were committed under `certificates/passed/` (b18eaac, 85a91d1) came from local runs and were moved to
`local-dev-logs/`; their former `CERTIFICATE` file is kept, content unchanged, as `LOCAL-RUN-PASSED.txt`
(the `SHA256SUMS` inside each lists it under its old name).
